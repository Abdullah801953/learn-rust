# Learn Rust

My Rust learning journey — a collection of small projects built while following the [Rust Book](https://doc.rust-lang.org/book/).

## Projects

| Project | Description |
| --- | --- |
| `hello_cargo` | First project — hello world with Cargo |
| `variables` | Variables, mutability, data types |
| `datatype` | Scalar and compound data types |
| `function` | Functions, parameters, return values |
| `control_flow` | `if`/`else`, loops (`loop`, `while`, `for`) |
| `ownership` | Ownership, references, borrowing |
| `guessing_game` | Guessing game from Chapter 2 |
| `main.rs` | Miscellaneous code from the book |

## Usage

Build and run any project:

```bash
cd <project-name>
cargo run
```

## Requirements

- [Rust](https://www.rust-lang.org/tools/install) (edition 2024)
